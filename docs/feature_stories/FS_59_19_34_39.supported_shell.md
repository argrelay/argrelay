Originally, `argrelay` supported only `bash` shell.

TODO: Update when `zsh` support is satisfactory.

Now, `zsh` shell is also supported.

There are multiple differences in syntax and Tab-completion integration between the shells.

There are separate sets of files to specialize on the differences:

*   `*.bash`
*   `*.zsh`

However, some files for `bash` are reused (executed) for `zsh`, if possible.
